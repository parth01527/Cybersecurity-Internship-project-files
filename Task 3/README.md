# ApexPlanet Cybersecurity Internship – Task 3

## Web Application Security

This task focuses on identifying, exploiting, and mitigating common web application security vulnerabilities in a controlled DVWA lab environment.

### Topics Covered

- SQL Injection
- SQL Injection Prevention using Prepared Statements
- Stored Cross-Site Scripting (XSS)
- Reflected Cross-Site Scripting (XSS)
- XSS Mitigation using Input Validation and Content Security Policy (CSP)
- Cross-Site Request Forgery (CSRF)
- CSRF Protection using Tokens
- Local File Inclusion (LFI)
- Remote File Inclusion (RFI)
- Burp Suite Proxy and Request Interception
- Burp Suite Intruder Fuzzing
- HTTP Security Headers
- Apache Security Header Configuration

## Lab Environment

- Kali Linux
- Damn Vulnerable Web Application (DVWA)
- Apache Web Server
- MariaDB
- Burp Suite
- SecurityHeaders.com
