# ApexPlanet Cybersecurity Internship - Task 1

## Cybersecurity Fundamentals, Networking, Cryptography & Professional Hacking Lab Setup

### Overview

Task 1 focused on building strong fundamentals in cybersecurity, networking, cryptography, Linux, and security tools while setting up a professional cybersecurity lab.

The lab was created using Kali Linux as the attacker machine and Metasploitable2 as the intentionally vulnerable target machine.

### Cybersecurity Basics

The following cybersecurity fundamentals were studied:

- CIA Triad: Confidentiality, Integrity, and Availability
- Phishing
- Malware
- DDoS
- SQL Injection
- Brute-Force Attacks
- Ransomware
- Social Engineering
- Wireless Attacks
- Insider Threats
- Common cybersecurity attack vectors

### Lab Environment Setup

A controlled cybersecurity lab was configured using virtualization.

- VirtualBox
- Kali Linux as the attacker machine
- Metasploitable2 as the target machine
- Private Host-Only network for isolated lab communication

The lab environment was used to safely practice cybersecurity concepts and security tools.

### Linux Fundamentals

The following Linux fundamentals and commands were studied.

#### File System Navigation

- pwd
- ls
- cd

#### File and Directory Permissions

- chmod
- chown

#### Package Management

- apt
- dpkg

#### Networking Commands

- ifconfig
- ping
- netstat
- traceroute

A Linux Cheatsheet containing commonly used commands is included in this Task 1 repository.

### Networking Basics

The following networking concepts were studied:

- OSI Model and its seven layers
- TCP/IP protocol suite
- DNS
- HTTP and HTTPS
- IP addressing
- Subnetting
- NAT

### Cryptography Basics

The following cryptography concepts were studied:

- Symmetric encryption
- Asymmetric encryption
- Hashing
- MD5
- SHA-256
- Digital certificates
- SSL/TLS

### OpenSSL Practical

A hands-on exercise was performed using OpenSSL to understand encryption and decryption of messages.

This provided practical experience with applying cryptography to protect information.

### Security Tool Familiarization

The following cybersecurity tools were explored:

#### Wireshark

Used to capture and analyze network packets and understand network communication.

#### Nmap

Used for network discovery, port scanning, and basic service enumeration.

#### Burp Suite

Used to understand web application traffic interception and basic web security testing.

#### Netcat

Used to understand TCP/UDP communication and basic network connections.

Task 1 established the foundation for the subsequent cybersecurity tasks by combining theoretical knowledge with practical experience in cybersecurity, Linux, networking, cryptography, and security tools.

The completed lab provides a controlled environment for continuing with hands-on cybersecurity and penetration-testing activities.
