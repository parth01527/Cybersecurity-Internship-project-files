1. Introduction

Cybersecurity is the practice of protecting computers, networks, applications, systems, and data from unauthorized access, attacks, damage, or disruption.

The main goals of cybersecurity are to protect the confidentiality, integrity, and availability of information and systems.

2. CIA Triad

The CIA Triad is a fundamental security model consisting of Confidentiality, Integrity, and Availability.

2.1 Confidentiality

Confidentiality means ensuring that information is accessible only to authorized users.

Example:
A company's employee salary information should only be accessible to authorized HR personnel.

Security controls:

Passwords
Multi-Factor Authentication (MFA)
Encryption
Access control
File permissions
2.2 Integrity

Integrity means ensuring that information remains accurate, complete, and has not been modified without authorization.

Example:
An attacker should not be able to modify the amount of money stored in a banking transaction.

Security controls:

Hashing
Digital signatures
File integrity monitoring
Access controls
Audit logs
2.3 Availability

Availability means ensuring that systems and information are accessible to authorized users when required.

Example:
An online banking service should remain available to customers when they need to access their accounts.

Security controls:

Backups
Redundant systems
Load balancing
Disaster recovery
DDoS protection
System monitoring
CIA Triad Summary
Principle	Meaning	Example
Confidentiality	Prevent unauthorized access	Encryption
Integrity	Prevent unauthorized modification	Hashing
Availability	Keep systems accessible	Backups and redundancy
3. Common Threat Types
3.1 Phishing

Phishing is a social engineering attack in which an attacker attempts to trick a person into revealing sensitive information or performing a malicious action.

Attackers commonly use fraudulent emails, messages, or websites that appear to come from trusted organizations.

Example:
An attacker sends an email pretending to be a bank and asks the victim to log in through a fake website.

Common defenses:

Verify suspicious emails and links
Use MFA
Avoid opening unknown attachments
Check website URLs carefully
Security awareness training
3.2 Malware

Malware is malicious software designed to damage systems, steal information, disrupt operations, or provide unauthorized access.

Common types include:

Viruses
Worms
Trojans
Spyware
Keyloggers
Ransomware

Common defenses:

Antivirus/endpoint protection
Regular software updates
Avoiding untrusted downloads
Email security
Network monitoring
3.3 Distributed Denial-of-Service (DDoS)

A Distributed Denial-of-Service attack attempts to make a service unavailable by overwhelming it with a large amount of traffic or requests.

A distributed attack usually involves many compromised devices sending traffic toward the target.

Impact:

Website downtime
Slow services
Increased network traffic
Loss of availability

Common defenses:

DDoS protection services
Rate limiting
Traffic filtering
Load balancing
Network monitoring
3.4 SQL Injection

SQL Injection is a web application vulnerability in which an attacker manipulates application input so that unintended SQL commands are executed by the database.

Potential impact:

Unauthorized access to database information
Modification or deletion of data
Authentication bypass
Data leakage

Common defenses:

Parameterized queries
Prepared statements
Input validation
Least-privilege database accounts
Secure coding practices
3.5 Brute Force

A brute-force attack attempts to gain access to an account or service by repeatedly trying different passwords or credentials.

Attackers may use automated tools to try large numbers of possible combinations.

Common defenses:

Strong passwords
Multi-Factor Authentication (MFA)
Account lockout policies
Rate limiting
Monitoring failed login attempts
3.6 Ransomware

Ransomware is a type of malware that can encrypt files or disrupt access to systems and then demand payment from the victim.

Ransomware can affect individuals, businesses, and organizations.

Potential impact:

Loss of access to files
Business disruption
Financial losses
Data exposure

Common defenses:

Regular offline or protected backups
Endpoint protection
Security updates
Email filtering
Network segmentation
User awareness training
4. Common Attack Vectors

An attack vector is a method or pathway that an attacker can use to gain unauthorized access to a system, network, application, or information.

4.1 Social Engineering

Social engineering involves manipulating people into revealing information or performing actions that may compromise security.

Examples include:

Phishing
Pretexting
Baiting
Impersonation

Example:
An attacker pretends to be an IT employee and asks a user for their password.

Protection:

Security awareness training
Verify requests through trusted channels
Never share passwords
Use MFA
4.2 Wireless Attacks

Wireless attacks target Wi-Fi networks or wireless communication.

Examples include:

Unauthorized access to Wi-Fi networks
Rogue access points
Evil twin attacks
Weak Wi-Fi passwords
Traffic interception on insecure networks

Protection:

Use WPA2/WPA3 security
Use strong Wi-Fi passwords
Keep wireless equipment updated
Avoid connecting to unknown networks
Monitor authorized access points
4.3 Insider Threats

An insider threat occurs when a person with legitimate access to an organization's systems or data misuses that access, intentionally or accidentally.

Insiders may include:

Employees
Contractors
Administrators
Third-party users

Example:
An employee copies confidential company information to an unauthorized personal device.

Protection:

Least-privilege access
Access reviews
Activity logging and monitoring
Data Loss Prevention (DLP)
Security awareness training
Separation of duties
5. Basic Cybersecurity Practices

Some fundamental practices that help protect systems include:

Use strong and unique passwords.
Enable Multi-Factor Authentication (MFA).
Keep operating systems and applications updated.
Use antivirus and endpoint protection.
Regularly back up important data.
Apply the principle of least privilege.
Monitor system and network activity.
Avoid suspicious links and attachments.
Use encryption to protect sensitive information.
Provide regular cybersecurity awareness training.
6. Conclusion

The CIA Triad provides the foundation for protecting information through Confidentiality, Integrity, and Availability. Understanding common threats such as phishing, malware, DDoS, SQL injection, brute force, and ransomware helps identify potential security risks. Attack vectors such as social engineering, wireless attacks, and insider threats demonstrate how attackers can target both technical systems and people.

Understanding these cybersecurity fundamentals provides a foundation for practical security activities such as network analysis, vulnerability assessment, traffic capture, and security testing.
